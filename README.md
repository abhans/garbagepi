# Garbage Classification using Raspberry PI
This project is an integrated system that combines a camera, electronic hardware (`Arduino` and `Raspberry Pi`), and a conveyor belt to automate waste processing.

The system employs computer vision techniques to detect and classify garbage in real time. The image classification algorithm, developed in `Python` and deployed on the `Raspberry Pi`, evaluates different AI models—applying fine-tuning techniques to enhance performance.

Based on the classification results, an Arduino-controlled setup directs servo motors to execute specific actions for effective waste segmentation on the conveyor belt.
